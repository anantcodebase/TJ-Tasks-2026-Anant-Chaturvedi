# Web Development — Responsive Website

## Task

Build a responsive website for a product of choice using **HTML, CSS, and JavaScript**.

## My Project

I built a responsive **NovaAI** website, an AI productivity product designed for creators, developers and teams.

The website includes:

* 🏠 **Home** — Introduction and main highlights
* ℹ️ **About** — Information about the product
* 🛍️ **Product** — Product features and services
* ⭐ **Testimonials** — User reviews and feedback
* 📩 **Contact** — Contact form and communication section

## Features

* Fully responsive design for different screen sizes
* Consistent color scheme and typography
* Clean and simple UI
* Interactive elements using JavaScript
* Mobile-friendly navigation
* Contact form interaction and validation

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Development Process

This is one of my first projects in web development. Until now, I have mainly been focusing on **DSA and programming fundamentals**, so I am still learning the development side of things.

I used **AI as a learning and development assistant** while building this project. It helped me understand concepts, structure the website, write parts of the code, and troubleshoot issues. The project was therefore **not built entirely by me from scratch**.

I am using this project as an opportunity to learn how web development works in practice and to understand the code and concepts involved rather than simply treating the project as a finished product.
